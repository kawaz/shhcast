## 裁定待ち

### 👺SC-Q1: ESP32 との通信方式は？

- [ ] a (推奨): mDNS + HTTP と ESP32 側 lease
- [ ] b: MQTT（家庭内に broker が常設の場合）

追加サーバ不要で、Mac のスリープ時にも lease 切れで消灯できるため a を推奨。詳細は [設計](DESIGN.md#デーモン--esp32)。

### 👺SC-Q2: CoreAudio だけが in-use の場合は？

- [ ] a (推奨): 赤
- [ ] b: 消灯
- [ ] c: 第 4 色

未知の会議アプリで誤消灯することを避けるため a を推奨。音声入力でも誤点灯する懸念がある。

### 👺SC-Q3: ランプの LED は？

- [ ] a: 単色 LED ×2（赤・緑）
- [ ] b (推奨): NeoPixel（WS2812 等）

状態追加時に配線変更が要らない b を推奨。

### 👺SC-Q4: idle の表示は？

- [ ] a (推奨): 消灯
- [ ] b: 薄い白などで点灯

話しかけてよい状態を直感的に伝える a を推奨。電源断との区別はつかない。

### 👺SC-Q5: Teams / Zoom のデスクトップアプリは対象にする？

- [ ] a (推奨): 今回は対象外（ブラウザ版のみ。デスクトップ版は CoreAudio に委ねる）
- [ ] b: 今回から対象にする

対象アプリごとの観測方式の検証が必要なため a を推奨。
